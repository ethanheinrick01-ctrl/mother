# Exam 5 media provenance

Six chapter-first films use the approved AI Voice Generator Clear voice. Generated within the existing shared 30K voice quota; observed usage rose from about 2K to 9K during generation while other exam work was concurrent. No purchase, upgrade, or paid runtime dependency. Study playback uses bundled files at $0 per use. Projects and signed download links remain private.

Original narration was checked against the assigned slides before generation. Local Whisper alignment uses the exact approved scripts for captions; transcription agreement was 98.75–99.69%. Five stage jumps per chapter follow aligned narration. Motion is schematic, and external artwork is never a factual source for scored answers.
