# NU545 Exam 6 assessment blueprint

This is a practice design, not an exam prediction. The supplied course schedule identifies Exam 6 on November 16–18, 2026 and the grading evidence assigns 40 points. Forty points does not establish forty questions. Question count, time limit, weights, allowed resources, attempts, and item mix are unconfirmed. The Unit 6 guide names Chapters 40–45; no requirement to retest earlier units was found in this packet.

Each mock uses 30 unique original four-choice roots, 45 minutes, and one point per first checked correct response. Unanswered items score zero. No released example is used as an original mock question. All 90 mock roots are disjoint from the 60 practice roots and from the other forms. Decisions differ in mechanism, stage, consequence, or application; merely changing an age or name does not create another root. Forms sample the supported concept clusters, not every missing textbook component.

The 25-question Boss selects supported originals across all six chapters from the existing practice bank; it adds no filler and claims no prior-unit cumulative requirement. An 80% threshold is the practice drill standard. Only a completed run can set a best score. Ending early saves an incomplete record.

Review uses the existing engine's missed/uncertain retrieval queue. Misses recur after two intervening items; low-confidence correct responses after four. Mastery requires two consecutive unassisted correct answers on distinct roots, with medium/high confidence on the latest response. A later miss returns for repair without deleting earned mastery. Reading, watching, and the twelve released self-checks do not earn mastery.

All modes require confidence before checking. Mocks retain the accepted immediate explanation behavior and are therefore guided timed practice, not a simulation of unknown official feedback rules. Corrections remain separate from the first scored response. Every run snapshots wording, options, rationales, source locators and revision; new content cannot rewrite an answered version.

The 52 guide prompts are represented individually in [coverage.md](coverage.md). Seventeen are Direct at supplied-slide depth, 34 Partial, and one Missing. Only supported claims enter scored keys; a mastery badge certifies the listed practiced cluster, not mastery of missing textbook material.
