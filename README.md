Study use costs $0 per model or voice call. The site and media are static. Progress stays in the same browser and hosted origin through ordinary code and content updates. Export/import supports moving to another browser or device. Browser storage can be cleared by the user or browser; export a backup to preserve it independently.

Run `node --test tests/*.test.cjs` for the content and progress checks. The verbatim intake comparison runs when the private source ledger is available locally; it is skipped in a public checkout. NU518 preservation is checked against its recorded accepted Git revision. Browser interaction, media playback, editorial review, and live deployment have separate receipts.

The public repository excludes raw intake decks, private author backups, family screenshots, and QA progress/answer-map fixtures. Scholarly figures and adaptation credits are bundled in the NU545 media directory. Editable animation source is retained beside the film assets.
